# Supporting Information mirrors

Frozen copies of the PLOS Supporting Information workbooks shipped with this
reproduction package. The scripts regenerate main-text Figures 1 and 2, S4 Fig,
and SI_5 table. Supporting Information S1, Figure 1 is exported from
[`../s1_figure1/`](../s1_figure1/).

| File | Manuscript item |
| --- | --- |
| `SI_2_MethodsTable.xlsx` | SI_2 table (methods catalogue; frozen copy, not rebuilt here) |
| `SI_3_ResourceAudit.xlsx` | SI_3 table (resource audit) |
| `SI_5_DatasetReuse.xlsx` | SI_5 table (dataset reuse) |

`../data/SI_3_ResourceAudit.xlsx` is the audit workbook. S4 Fig is drawn from
`../data/audit_source.csv`. `../dataset_reuse/build_si_4_xlsx.py` rebuilds
SI_5 table from the CSVs in `../dataset_reuse/data/`.

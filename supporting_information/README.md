# Supporting Information mirrors (S2–S4)

Frozen copies of the PLOS Supporting Information workbooks shipped with this
reproduction package. Supporting Information S1 is the taxonomy PDF that
accompanies the article; it is not regenerated by the scripts here.

| File | Manuscript item |
| --- | --- |
| `SI_2_MethodsTable.xlsx` | Supporting Information S2 |
| `SI_3_ReproducibilityAudit.xlsx` | Supporting Information S3 |
| `SI_4_DatasetReuse.xlsx` | Supporting Information S4 |

`../data/SI_3_ReproducibilityAudit.xlsx` and `../dataset_reuse/SI_4_DatasetReuse.xlsx`
are the working copies used by the regeneration scripts.
